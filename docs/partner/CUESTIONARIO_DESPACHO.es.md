# Cuestionario — carpeta de cliente

**Para:** el despacho  
**De:** Petr (programa de gestoría)  
**Tiempo:** unos 20–30 minutos, mejor con **una carpeta real** delante  
**Cómo devolverlo:** responda encima, en Word / Google Docs, o a mano y mándeme foto / PDF por WhatsApp o correo.

No hay respuestas incorrectas. Si algo no lo hace usted, ponga **«no lo hacemos»**.  
Si un plazo cambia según el caso, escríbalo con sus palabras.

El programa copiará **las dos hojas que imprime para cada carpeta**. La idea es que, cuando esté relleno, el sistema avise de plazos y de papeles que faltan — para ahorrar tiempo, llamadas y recargos.
