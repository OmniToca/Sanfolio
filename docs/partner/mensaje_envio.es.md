# Mensaje para enviar (español)

Copiar a WhatsApp o correo. El archivo del cuestionario va adjunto (Word / PDF / o enlace).

## Corto (WhatsApp)

Hola, como hablamos estoy preparando el programa a partir de las **dos hojas** que imprime para cada carpeta.

Para no inventar plazos ni papeles, ¿puede rellenar este cuestionario? Son unas 20–30 minutos. Mejor con **una carpeta real** delante. Si algo no lo hace, ponga «no lo hacemos».

Puede escribir encima, o a mano y mandarme foto.

Mientras tanto ya monto en el ordenador la ficha (cliente, escritura, agua, luz, gas, comunidad, SUMA, etc.). Cuando me lo envíe, encajo los plazos como los usa usted.

Gracias.
